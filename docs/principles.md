# Principles

## Human as selector, not transporter

Humans retain intent: choosing scope, deciding relevance, giving consent, and reviewing outcomes. Tools should take responsibility for mechanical handoffs when they can do so safely.

## Observe before prescribing

Each entry should make the current flow visible before recommending APIs, integrations, plugins, shared storage, or UI changes.

## Be precise about the boundary

MCP and similar protocols connect an LLM with an external system. Meat Protocol also concerns the UX of indicating a specific, already-visible target from a human to that LLM. These are complementary layers, not rival ideas.

## Preserve history

A workaround or later integration can make a relay obsolete. Keep the entry and mark its status; it is a record of how interfaces changed.

## Keep the joke humane

The phrase is intentionally ridiculous. The catalog should not ridicule people, accessibility needs, or products. The joke is that remarkably capable systems can still require a person to carry a pointer across the room.
