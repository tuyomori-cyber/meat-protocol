# MP-002 — ファイルパス Relay

## 状況

人がエディタまたはファイルブラウザでファイルを見つけ、エージェントも同じリポジトリにアクセスできるのに、パスをコピーしてチャットへ貼り付ける。

## 現在のフロー

```text
エディタのファイルツリー
  ↓ player.rs を見つける
人間
  ↓ 相対パスをコピー / チャットへ貼り付け
リポジトリアクセスを持つエージェント
```

## 人間が判断すること

`player.rs` がエージェントに調べてほしいファイルであること。

## 人間が運ぶこと

パスまたは識別子という参照情報。

## なぜ存在するのか

どちらも同じワークスペースを指している場合でも、エディタでの選択とエージェントのコンテキストは別々のインターフェースだから。

## 改善の可能性

**エージェントへ参照を送る** のような、権限を考慮した明示的な操作を追加する。ツールが安定した参照を運び、人はファイル選択を保持する。
