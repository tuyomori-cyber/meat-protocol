# MP-006 — 再説明 Protocol

## 状況

アシスタントを変えたり新しいセッションを始めたりした後、人がすでに決着した背景、根拠、制約を記憶から再構築する。

## 現在のフロー

```text
過去の議論と決定
  ↓ 記憶から再構成
人間
  ↓ もう一度説明
新しいセッションまたはシステム
```

## 人間が判断すること

過去の決定のうち何が関連し続けるか、次のコンテキストと共有すべきか。

## 人間が運ぶこと

移植可能で確認可能な受け渡しがないために、再構成して語り直す既定のコンテキスト。

## なぜ存在するのか

会話状態がサイロ化、一時的、アクセス不能、または安全に転送するには不透明すぎることが多いため。

## 改善の可能性

見えないコンテキスト全体の転送ではなく、決定、制約、情報源、不確実性を含む、編集可能でユーザーが所有する受け渡しパケットを提供する。

## ステータス

`Common`
